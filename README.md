# BruteForce_Password_Algorithm - A Simple Brute-Force Algorithm to Crack a Password

This repository contains a simple Brute-Force algorithm implemented in Python to crack a password.

## Requirements

The project requires Python 3.8 or higher.

## Installation

To install the dependencies, run:

```sh
pip install -r requirements.txt
```

Note: There is no `requirements.txt` file provided in this repository.

## Usage

To run the Brute-Force algorithm, execute the following command:

```sh
python main.py words.text
```

This will read passwords from `words.text` and attempt to crack them using a brute-force approach.
